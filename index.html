Projets

PhishShield AI+

Python, scikit-learn, LIME. Projet académique.

Plateforme de détection explicable des e-mails de phishing. Elle combine TF-IDF et Random Forest (3 classes, score F1 de 0,91 pour le phishing, entraînement sur 18 670 e-mails Enron-Spam et Kaggle), l’analyse d’URL, les vérifications SPF/DKIM/DMARC et l’explicabilité avec LIME.

Elle ajoute un score de risque de 0 à 100, une API REST, un tableau de bord et une surveillance en temps réel des boîtes mail via IMAP.

Voir le code sur GitHub

pfSense, OpenVPN, VMware.

Architecture LAN/WAN/DMZ segmentée avec règles de pare-feu, accès distant OpenVPN, sécurisation SSH et filtrage DNS. Les politiques de trafic ont été validées par des tests.
